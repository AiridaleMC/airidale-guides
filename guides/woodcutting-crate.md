# Woodcutting Crate

## Earning and Using Keys

Woodcutting Crate Keys can be earned while cutting wood. Your virtual key total appears in the Crates menu.

- Left-click the Woodcutting Crate to use one virtual key.
- Shift-left-click to open up to 10 keys at once.
- Right-click the crate to preview its current rewards and displayed chances.

Some Woodcutting Keys may also exist as physical Oak Log items.

## Current Rewards

The Woodcutting Crate can reward:

- $1,500.
- 75 Scrap.
- A 1.5× Woodcutting mcMMO voucher.
- A `Wood` tag voucher.
- One Rare Crate Key.
- Host Armor Trim.
- Vex Armor Trim.
- Spire Armor Trim.
- Snout Armor Trim.
- Raiser Armor Trim.

Use the in-game crate preview for the current displayed chances before opening a key.
