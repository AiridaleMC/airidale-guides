# Referral Program

## Who Can Be Referred

Referrals connect an existing Airidale player with someone joining for the first time.

- The invitation must be created before the new player joins.
- The invitation must use the new player's exact Minecraft name.
- Existing players cannot be referred retroactively.
- A confirmed referral cannot be transferred to someone else.

## Referring a New Player

1. The existing player runs `/referral code` to view their six-character referral code.
2. Before the new player joins, the existing player runs `/referral invite <playerName>`.
3. The invitation remains valid for seven days.
4. The new player receives a referral prompt when they first join.
5. The new player runs `/referral confirm <code>` within 60 seconds.
6. The new player has three attempts to enter the correct code.
7. When the referred player reaches C4, both players receive one virtual Epic Crate Key.

The players do not need to be online together when the reward is delivered. Delivery can take up to about one minute after the referred player reaches C4.

## Managing Invitations

- `/referral invites` lists your pending invitations.
- `/referral cancel <playerName>` cancels a pending invitation.
- `/referral decline` declines the referral offered on first join.
- You can have up to 25 pending invitations.
- You must wait 30 seconds before creating or refreshing another invitation.
- An expired invitation can be created again.

## When a Referral Expires or Is Declined

The first-join offer ends if the new player:

- Does not confirm within 60 seconds.
- Disconnects before confirming.
- Uses `/referral decline`.
- Enters an incorrect code three times.

If the seven-day invitation expires before the new player joins, the inviter can create a new one.
